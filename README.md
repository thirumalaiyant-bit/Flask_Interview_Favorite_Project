
# Interview Favorites Flask App

A simple Flask web application that allows users to add and delete interview favorites.

## Features

- Flask routing
- GET and POST requests
- SQLite database
- Add favorites
- Delete favorites
- Bootstrap user interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- Bootstrap

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

python app.py
